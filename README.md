## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(molecularBio)
## basic example code
analyze_qPCR(path_to_qPCR_res = "/PAHT/TO/WellResult.csv",
             path_to_group_label = "/PAHT/TO/grouplabel.csv",
             out_dir_path = "/PAHT/TO/output_dir",
             controls = c("18S", "GAPDH", "RPL13A"),
             plot_all = TRUE,
             plot_individual = FALSE
             )
```
